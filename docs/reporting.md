# Reporting what you find

Use [Issues](https://github.com/jariw2/ocad_runner-releases/issues/new/choose) in this repository. There are two forms: **Bug** for something that does not work or breaks, and **Feedback** for something you like, miss or find hard to use. You need a free GitHub account.

## A good bug report

- **The version.** It is shown in **About** (on the main menu), for example `0.11.0-prealpha`.
- **Your computer:** Linux, Windows or macOS (Apple Silicon or Intel).
- **What happened, and what you expected.**
- **What you did before it happened,** step by step, as far as you remember. Say if it happens every time.
- **A screenshot,** or the text of an error message, if there is one.

If the game crashed, the newest log file in the `logs` folder inside the game's user folder helps. Where that is, is in [Install](install.md).

## Feedback

Say what you tried to do, and what you would have liked to happen. Small things are welcome too: wording, a key that is awkward, a button that is hard to find.

## Please remember

This is a pre-alpha program and its [roadmap](roadmap.md) is long, so many things you miss are already planned. A report is still useful: it tells the author which matter most. Your files may stop opening in a newer version, so keep copies of anything that matters to you. The [terms](../TERMS.md) apply.
